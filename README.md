# Swiss Mobile Service Provider Library

The **Swiss** **M**obile **S**ervice **P**rovider **Lib**rary (swissmsplib) is a client library that allows interacting with Swiss mobile service providers as if they would expose a public API.


## Development

### Versions

Build and tested using dev container (see [devcontainer.json](.devcontainer/devcontainer.json))
- Debian 12
- Python 3.11
- Poetry 2.1

### Poetry

This project uses poetry for package and venv management.

### Black

This project uses black for source code formatting.
